# Bài tập Quản lý Sinh Viên (React Native + Expo)

## Chức năng đã hoàn thành:
- CRUD Sinh viên (Thêm, Xem chi tiết, Sửa, Xóa).
- Lưu trữ dữ liệu cục bộ bằng AsyncStorage.
- Đúng 3 trang: Danh sách, Chi tiết (Modal), Thêm/Sửa.
- Có hộp thoại xác nhận trước khi Sửa/Xóa.
- Đa ngôn ngữ (Tiếng Anh / Tiếng Việt) tự động nhận diện theo thiết bị.
- Chọn ảnh Avatar từ thư viện hoặc chụp camera.

## Công nghệ sử dụng:
- React Native (Expo SDK 58)
- Expo Router
- AsyncStorage
- i18n-js & expo-localization
- expo-image-picker
